Sistema de Reserva de Carros

Sobre o projeto

Projeto acadêmico desenvolvido durante o curso de Análise e Desenvolvimento de Sistemas (ADS), com o objetivo de praticar a criação e organização de um banco de dados para um sistema de reserva de carros.

Tecnologias utilizadas

* MySQL
* SQL
* MySQL Workbench

Estrutura do projeto

O banco de dados foi desenvolvido para organizar informações relacionadas a:

* Sedes
* Classes de carros
* Clientes
* Carros
* Reservas

Como executar

1. Abra o MySQL Workbench.
2. Abra o arquivo SISTEMA DE RESERVA DE CARROS - LETICIA.sql.
3. Conecte-se ao seu servidor MySQL.
4. Execute os comandos SQL para criar e estruturar o banco de dados.

Objetivo de aprendizagem

Praticar comandos SQL, criação de bancos de dados, tabelas, chaves primárias e relacionamentos.
